# LimiterBeacon

LimiterBeacon enables scalable, fault-tolerant real-time data processing through dynamic rate limiting, fueling a high-performance data engine system.

LimiterBeacon is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/LimiterBeacon.git`
2. `cd LimiterBeacon`
3. Install in editable mode: `pip install -e .`

## Configuration

LimiterBeacon is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
